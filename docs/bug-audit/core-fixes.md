# Core bug fixes

Ownership: `crates/opendictate-core/**`. Changes implement B014, B016–B024, B032, B034–B036 and B062. The unsupported LocalSlm branch also now returns an explicit error for the frontend's B025 fix. No commits, model downloads, paid APIs, production deletion, or live microphone recording were performed.

## Verification

- `cargo test -p opendictate-core --lib --locked`: 107 passed, 5 ignored after the final changes. The five ignored tests are the three existing microphone/WAV integration tests and two new tests requiring installed native model assets.
- `cargo test -p opendictate-core --lib --locked installed_offline_nemo_hotwords_are_native_safe -- --ignored --nocapture`: passed using existing Parakeet TDT 0.6B and offline Unified assets (14.04 seconds).
- `cargo test -p opendictate-core --lib --locked installed_streaming_hotwords_and_finish_are_native_safe -- --ignored --nocapture`: passed using existing caption Zipformer, Unified streaming, and FastConformer CTC assets (24.74 seconds). Exercises dictionary requests, finish twice, reset, and a second utterance.
- `cargo clippy -p opendictate-core --lib --locked`: completed successfully, retaining six existing style warnings (Pulse chunk iteration, two engine needless borrows, KWS nested conditional, Whisper readiness `map_or`, and command punctuation matching). No strict-Clippy cleanliness claim.
- Owned changed Rust files formatted with `rustfmt --edition 2021 --config skip_children=true`; `git diff --check -- crates/opendictate-core` passes.

## Native evidence and API coordination

Context7 was consulted for CPAL, ureq, and Sherpa ONNX, then checked against the installed pinned sources. In particular, the pinned [NeMo offline implementation](https://github.com/k2-fsa/sherpa-onnx/blob/v1.13.4/sherpa-onnx/csrc/offline-recognizer-transducer-nemo-impl.h), [online transducer implementation](https://github.com/k2-fsa/sherpa-onnx/blob/v1.13.4/sherpa-onnx/csrc/online-recognizer-transducer-impl.h), and [hotword encoding implementation](https://github.com/k2-fsa/sherpa-onnx/blob/v1.13.4/sherpa-onnx/csrc/utils.cc) require a supported decoder and nonempty valid modeling unit. No fatal baseline native overload was executed or treated as a catchable Rust panic.

`StreamingRecognizer::finish` pads one second of silence, calls `input_finished`, and drains; it is idempotent. Reset after finish creates a fresh native stream because the completed feature pipeline cannot accept a new utterance. The session owner was notified when all APIs became available and changed dictionary inputs to newline-separated phrases, retaining spaces and removing the previous underscore/bare-score format.
