## Contracts and remaining platform limits

- Requires native `ensure_model(id)` to resolve only after extraction/dependencies, terminal events to follow cleanup, and `models-ready` to include `{ file: id }` (frontend tolerates an absent file). The session worker confirmed this contract.
- Requires native `test_snippet(text)`, `paste_clipboard(text)`, and `undo_last_insert()` to perform the verified external-focus handoff and refuse unsafe injection. Parent owns these commands.
- Native `transcript` events supply insertion/copy/error outcomes. Plain stop responses carry only text/duration and therefore cannot independently enable Undo. The session worker clears native stale `last_inserted` on copied/failed results.
- Native settings default `input_target` to `text` and validate `text`/`terminal`; parent routes injection/editing commands using that profile. Actual Bash/Zsh key behavior remains a native/platform integration check.
- IPC mocks intentionally avoid downloading models, recording real audio, invoking paid cloud services, changing user data, or injecting input into another app. Native focus, microphone permissions, model installation, hotkey behavior, and cross-window races still need the native suite/platform smoke checks.
- Context7 Vitest documentation was fetched before test setup; Base UI Select documentation was fetched for the target-selection behavior test. React review and verification skills were used during final inspection. No further subagents were created.
